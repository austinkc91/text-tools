# TextForge — Free Online Text Tools

## Overview
A collection of 12 free, client-side text transformation tools deployed as a static site on GitHub Pages. Designed to drive organic SEO traffic and cross-promote paid products (Prompt Vault, BAS Field Guide).

## URL
https://austinkc91.github.io/text-tools/

## Revenue Model
- **Phase 1 (current)**: Free tool, email capture, cross-promotion of paid products
- **Phase 2**: Add Google AdSense when traffic justifies it
- **Phase 3**: Premium tools behind paywall (advanced regex, bulk processing, API access)

## Tools Included
1. Case Converter (9 modes: upper, lower, title, sentence, camel, snake, kebab, pascal, toggle)
2. Word Counter (chars, words, sentences, paragraphs, reading time)
3. JSON Formatter (pretty print, minify, sort keys)
4. Base64 Encoder/Decoder
5. URL Encoder/Decoder
6. Slug Generator
7. Lorem Ipsum Generator
8. Hash Generator (SHA-256, SHA-1)
9. Text Diff
10. Regex Tester
11. Markdown Preview
12. Text Cleaner (8 modes: fix spaces, remove empty lines, trim, dedup, sort, reverse, number, strip HTML)

## Tech Stack
- Pure HTML/CSS/JS (no dependencies, no build step)
- Static hosting on GitHub Pages (free)
- FormSubmit.co for email capture
